# Flowglass art prompts

17 characters: 4 families × stages 1–4, plus the Timekeeper (stage 5, shared by every
family). Generate them with any image tool whose license allows commercial use, save them
under the file names below, and the app can swap its vector art for them.

## How to get a consistent set

1. Start with **stage 1** of a family. Regenerate until you love it.
2. For stages 2–4 of that family, give the tool your own stage-1 image as the character
   reference (image-to-image / "character reference"), so it reads as the *same creature
   growing up*: same eye shape, same face, more size and detail each stage.
3. Keep the framing identical: square, full body, centered, same camera angle.
4. Only use your own generations as references, never someone else's art.

**Output:** 1024 × 1024 PNG, transparent background (or plain light grey, and remove it
afterwards). Save as `assets/images/creatures/<file>.png`.

**Style block** (paste after every prompt):
> glossy 2D digital illustration, original chibi creature design, big head small body,
> thick clean dark-purple outlines, soft cel shading with gentle gradients, warm rim light,
> vibrant saturated colors, expressive cute-but-sassy face, game mascot sticker quality,
> full body, centered, three-quarter view, plain light grey background, no text

**Negative prompt** (if the tool has one):
> text, letters, watermark, signature, logo, photo, realistic, 3D render, human, extra
> limbs, cropped, existing game or anime characters

**Rules:** original characters only. Don't name or imitate existing games, anime, brands
or celebrities ("in the style of …", real faces, catchphrases). The app sells Pro, so
that's a takedown risk.
